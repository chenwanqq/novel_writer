# 采用、推演与分支

“假设如此会怎样”保存 hypothesis/inference + candidate，不修改正式前提。“采用这个制度”是明确采用；校验后提交，无需再次确认。“沿此假设另开世界线”从当前修订建立分支。“先聊聊”只保存候选和讨论。

先看世界分支，再看有效时间，最后看作者明确修订关系。不同时间可以具有不同属性值。有效时间使用作者定义的数值轴；不明历法保留说明，避免虚构日期换算。

事实的 `data.subject/attribute/value` 用于确定性互斥检查；模型还需审查政治、人物、因果等自然语言冲突。废弃用 deprecated 保留历史；`depends_on` 记录前提，`supersedes` 记录修订关系。

推演描述前提、直接结果、条件性结果、参与者反应及反作用，并区分“可能发生”和“已经发生”。不要为了戏剧性把制度推演必然导向危机。

共享世界变更不能由作品工具提交。把作品配角提升为公共设定时，提取作品依据，确认身份、时间与已有关系，再使用世界变更集。
