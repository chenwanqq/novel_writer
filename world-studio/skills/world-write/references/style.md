# 文风、人物声音与编辑

作品级记录叙述视角、距离、语言节奏、解释密度与偏好；人物级记录注意什么、面对不同关系如何表达、怎样回避或求助；场景级允许审讯、家宴、独处等不同节奏。

风格尚未稳定时，对同一小场景给出少量有区别的版本，由作者选择或修改。认可段落保存 example；`style_record_edit` 保存原稿 ID、修改稿、理由和适用标签。不要把自己猜测的偏好记为作者选择。

范例只指导表达，不能把其中人名、事件、世界事实迁入当前作品。优先选叙事功能相似的范例，如间接拒绝、信息隐瞒，而不仅是相同题材。

编辑顺序：结构（因果、选择、铺垫）→ 场景（视角、知识泄漏、时空、必要性）→ 文字（节奏、解释、重复、声音）。每条问题指出文本与理由，再选择性修订；不让多轮泛泛润色磨平人物声音。

具体检查：人物是否过度理解自己的动机？对白是否过于完整？是否总在结尾总结主题？动作能否承担一部分解释？对生活质感的细节是否来自人物注意力和处境？这些是诊断问题，不是绝对禁令。
