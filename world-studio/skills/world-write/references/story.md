# 从角度到场景

以创作简报为边界：谁在经历、他能知道什么、什么时期与地区、追踪何种问题、以何种形式表达。

雪花式逐级展开：一句话故事 → 概要 → 主要人物与转折 → 场景清单。采用远处粗纲、近处细纲，不要求先填满整部长篇。

剧情弧保存压力、可选行动、实际选择、收益、代价和状态变化。人物弧保存信念、盲点、关系与底线的变化。伏笔保存埋设、表层解释、预期兑现及开放状态；计划兑现不等于正文已经兑现。

场景任务至少有唯一 `reading_order`、可选 `world_time`、`pov`、`location`，以及目标、阻力、选择与前后变化。引用放入 refs，跨场景因果也显式引用，以便后续影响检查。

Scene/Sequel 用于检查行动如何导致后果、反应如何引出下一次决策。安静场景也可通过理解、关系或氛围变化产生作用，不机械要求失败。

先保存 scene 产物，再编译上下文、写正文并 `prose_save`。人物知道的内容、误解、读者已知与本场计划揭示的信息分别考虑。人物说话应有当前目的、避讳和关系压力，不能只是轮流向读者解释设定。
