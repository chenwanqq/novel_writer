# 世界中的作品

先 `work_list`／`work_read` 查找作品。新作品通过 `world_list`、`world_read` 选择明确世界修订，再 `work_create` 保存创作简报：观察者、时期、地点、核心问题、形式、声音、可补充与受保护内容。不要默认“最新世界”会永远适合已有作品。

- 构思与场景：读 [故事设计](references/story.md)。用 `work_save` 保存计划产物，再写正文。
- 文风与编辑：读 [风格与声音](references/style.md)。保存可检索范例和作者修改。
- 正文采纳、前文修订、世界升级：读 [连续性](references/continuity.md)。计划和草稿不推进已发生状态。

写每场前调用 `scene_context`。检查缺失引用、needs_review 与截断；必要时补读 `world_read`／`prose_read`。只使用作品绑定版本的空间约束。场景需要的额外事实可以检索，不能把整个资料库都当成人物已知信息。

## 边界与完成标准

作品可以在约定自由度内补充普通人物、私人关系与局部事件，默认保存在本作。改变公共制度、主要历史、地理或已有设定时，明确提出世界变更，切换 `world-input`；不为了推动情节直接改 canon。

正文由当前 Codex 模型创作，本插件不另开模型请求。每轮返回具体产物和成功保存的修订。作者明确说“采用正文”才调用 `prose_adopt`；要求试写不等于采用。

提供带具体文本依据的编辑判断，不用“人味评分”代替解释。不强制每个人物成长、每场惨败、每句潜台词或固定段落长度。
