# 导入与检索

导入不等于采用。`Ingestion.ingest` 保存原文、身份与可定位单元；文本保持一个完整文档，ChatGPT JSON 的每个叶分支保持一条完整祖先路径。共享消息可以出现在不同路径，但不会混合替代结局。

模型通过 `units` 列表和 `read` 字符分页读取。长文必须读完前提与后续纠正，再提出候选变更集，明确来源 `source_id/locator`。`reviewed` 记录覆盖说明和相关变更集；只是提取进度，不自动提交正式设定。含图片的聊天会标记附件存在，正文导入不代表附件已处理。

来源身份：baseline（作者指定基线）、chat、reference、draft、adopted_work。身份不同不自动互相覆盖。未知 JSON 结构拒绝导入，先转换为 TXT/Markdown。支持直接粘贴当前可访问聊天，但不后台获取账户历史。

中文检索采用 Unicode 子串、空格分隔多关键词 AND、标签与显式关联扩展。默认只返回 accepted；讨论检索可显式取消状态过滤。首版按指定版本内存扫描，超大资料库的全文索引是后续优化。
