# V1 验收记录

## 可复现检查

```sh
cd world-studio
uv sync --frozen --group dev
uv run pytest
uv run ruff check src tests scripts
cd web
npm ci
npm run build
npm test
```

Python 用例覆盖世界历史重建、分支隔离、过期版本、并发写入、幂等、事务回滚、导入恢复、中文检索、地图条件与版本、作品隔离、正文采纳和前文修订。最后新增的完整工作流及导出边界用例已独立复验；前端构建包含 TypeScript 检查，几何坐标与缩放用例通过。

`tests/test_transfer.py::test_complete_author_workflow` 在临时目录连续走通：导入旧资料并记录采用决定 → 创建分支 → 编辑大陆和城市地图 → 两部作品与场景规划 → 保存及采纳正文 → 修订已采纳场景 → 标记旧连续性待审阅 → 检查世界变化影响 → 显式升级绑定版本且保留正文 → 备份恢复并逐项比较。

`tests/test_mcp.py` 读取实际 `.mcp.json`，用官方 MCP 客户端启动 stdio 服务，执行初始化、工具列表、世界创建和读取、资料导入及错误调用。插件 manifest 和两个 Skill 的官方本地校验脚本通过。安装脚本的 dry-run 通过；这项检查没有代替真实的用户级安装。

## 浏览器交互

本地地图页面实际完成了：创建世界和空白地图、添加两个地点、路线与多边形区域、拖动地点和顶点、草稿保存及刷新恢复、提交新世界版本、历史只读查看、路线耗时查询、PNG 与 SVG 导出。

底图流程使用真实 PNG 文件验证上传、保留坐标替换、按新尺寸缩放以及移除。检查确认缩放后的画布尺寸改变，移除后对象仍保留。创建和确认使用页面内对话框，并在 Codex 内置浏览器验证，避免依赖宿主不支持的原生 prompt。

## 验收边界

合成演示资料由 `demo` 命令写入独立目录，拒绝覆盖已有世界。具体文学判断见[演示文本审阅](writing.md#演示文本审阅)。程序校验显式结构和证据，不声称能自动发现所有隐含矛盾或评定小说质量。

首版使用完整快照、Unicode 扫描检索和字符上下文预算；尚未进行超大资料库性能验收。数据、运行令牌和浏览器临时截图均不进入源码提交。
