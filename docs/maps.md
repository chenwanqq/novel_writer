# 世界地图

地点引用实体和地图；路线引用同地图的两地点；区域用多边形点列，可关联实体。画布坐标支持负值，比例尺缺失时不计算真实距离。

路线通行条件是由作者明确提供的条件名称。查询传入已满足条件列表；未满足或尚未确认条件不会被当作已开放。已知最短耗时路径返回该路径的最小和最大耗时，不声称找到了所有路径的全局最大时间。

地图编辑保存为独立草稿，提交通过通用世界变更集。世界更新后，`rebase` 三方比较原版本、草稿、最新世界；不冲突的对象重新应用，同对象冲突返回双方内容并保留草稿。查看旧地图不会移动世界分支头。

图片限 20 MB、4000 万像素以内的 PNG/JPEG/WebP。图片按内容地址保存；移除底图不影响地点对象。附属资源和地图在备份中一同保存。

启动：`uv run world-studio --data ../data serve`。本地服务只监听 `127.0.0.1`，终端输出的带 token 链接只用于本机浏览器，勿分享。HTTP `/api/<method>` 接收 JSON、Bearer token，复用领域服务。界面构建后由同一服务提供，无需另开前端开发服务器。
